# dmsqlq —— 达梦 DM8 SQL 日志解析工具

> 把 `dmsql_*.log` 里带 `?` 的 SQL，按日志中的 `PARAMS` 行还原成**真实参数值**，
> 输出可直接复制到 disql 执行的语句；另可生成一份能直接看的**性能统计报告**。

**单个可执行文件 · 不连数据库 · 不建表 · 不装运行时 · 不联网 · GB 级日志秒级扫完。**

当前版本：**V2.7**（2026-10-02）

## 三十秒上手

```bat
dmsqlq                          不带参数 → 显示用法，并告诉你「当前目录有什么、下一步敲什么」
dmsqlq .                        处理当前目录，输出全部可执行 SQL
dmsqlq . -m 1000                只要执行超过 1 秒的语句
dmsqlq . -s                     出统计报告（<日志名>_报告.html），生成后自动用浏览器打开
dmsqlq . -s -Q                  同上，但不自动打开浏览器（批处理连跑多份时用）
dmsqlq . -S                     只在终端扫一眼统计，不出文件
dmsqlq . -B 20 -o slow.sql      导出最慢 20 条的完整 SQL
```

## 能解决什么

| 场景 | 命令 |
|---|---|
| **看全局**：哪类语句最耗时、哪张表最热、哪条最慢、有没有锁等待 | `dmsqlq /dmdata/log -s` |
| **导出慢 SQL 去复现** | `dmsqlq . -m 2000 -o slow.sql` |
| **锁等待定位**（给出等待方事务号 + 表 ID + 锁模式） | `dmsqlq . -x 10133085467 -N` |
| **按表名 / 用户 / 时间段挑语句** | `dmsqlq . -l t_rim_invoice -n 50` |
| **复现某个事务** | `dmsqlq x.log -x 10130765548 -N` |
| **压缩包直接喂 / 多目录 / 通配符** | `dmsqlq dm_log.tar.gz -B 10 -o slow.sql` |
| **排除干扰项**，只看真正的业务负载 | `dmsqlq . -m 1000 -E CAL,ANALYZE,DBMS_STATS` |
| **交付给开发商做 SQL 优化**（Excel 交付件） | `dmsqlq . -e 交付.xlsx` |

## 统计报告内容

概览 / 类型分布（含耗时占比）/ 耗时分布（含分位数）/ 热表（含读写比）/ 吞吐（QPS·TPS）/
最慢语句 / 最耗时模板 / 用户与客户端 / 长事务（含利用率）/ 锁等待 /
审计与恢复定位（危险操作·结构变更·LSN）/ 采集配置体检 / 判读提示。

输出格式按后缀自动选：`.html`（单文件带图表，可打印为 PDF）、`.md`、`.xlsx`、其他为纯文本。
